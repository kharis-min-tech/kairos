# Kairos — Modern Sanctuary

Kairos is a church operations console. The design system, **Modern Sanctuary**,
is calm, structured, and premium: architectural spacing, layered surfaces,
restrained color, and confident purple/gold emphasis.

## Getting started

- **Principles** — see [`DESIGN.md`](https://github.com/kharis-org/kairos/blob/main/DESIGN.md) at the repo root.
- **Component reference** — see [`docs/DESIGN-COMPONENTS.md`](https://github.com/kharis-org/kairos/blob/main/docs/DESIGN-COMPONENTS.md).
- **Tokens** — see [`packages/ui/tokens.json`](https://github.com/kharis-org/kairos/blob/main/packages/ui/tokens.json).

## What's in this Storybook

**16 components — 13 primitives + 3 composites**, all shipped from `@kairos/ui`:

### Primitives

`Badge` · `Button` · `Card` · `Checkbox` · `CustomSelect` · `Dialog` · `Input` ·
`Label` · `NumberStepper` · `Select` · `Table` · `Tabs` · `Textarea` · `TimeSelect`

### Composites

`ConfirmDialog` (+ `useConfirm` hook) · `DateSelect` · `PasswordStrength`

## Palette

The core brand colors are royal purple (`#5D3FD3`) and gold (`#f8b537`). See
the **Colors** story for the full palette.

## Theme

Every component supports light and dark themes. Toggle with the sun/moon icon
in the Storybook toolbar.

## Adopting the system

If you're another Kharis team adopting Modern Sanctuary:

1. Read `DESIGN.md` for the principles.
2. Browse this Storybook for the visual catalog.
3. Follow `packages/ui/README.md` for installation.
4. Refer to `docs/DESIGN-COMPONENTS.md` for per-component API.
