# Mɛmbaship Klas

<SectionClip slug="platform/membership" />

Di Mɛmbaship pej de ron di fɔ-wik mɛmbaship klas: di program we de mek pɔsin tru-tru Mɛmba fɔ di chɔch.

::: warning Wetin "Mɛmba" min ya
Insay dis chɔch, Mɛmba na pɔsin we dɔn finish di fɔ-wik mɛmbaship klas ɛn dɔn gɛt in satifiket. Nɔtin ɛls nɔ de gi am. If yu kam ɛvri Sɔnde fɔ wan ia, dat nɔ de du am. If yu sav insay dipatmɛnt, dat nɔ de du am. If yu de lid fɛloship, dat nɔ de du am. If yu finish di Nyu Biliva program, dat nɔ de du am. If yu jɔs opin akawnt, fɔ shɔ dat nɔ de du am.

Ɛvribɔdi we gɛt rɛkɔd insay Kairos de pan di dayrɛktri ɛn dɛn de kawnt am insay atɛndans, bikɔs na pat pan di chɔch ɛn dɛn fɔ kawnt am. Bɔt di **Mɛmba** nɔmba pan di dashbɔd ɛn insay ripɔt de kawnt di wan dɛn we finish di klas, ɛn di **Ritɔna** nɔmba de kawnt di fetful wan dɛn we nɔ du di klas yet. Ɔltu na tru; bɔt nɔto di sem nɔmba.
:::

## Udat de ron am

Di program na **ɔl-di-chɔch**, nɔto pa-branch. Kɔhɔt dɛn de tek pipul frɔm ɛvri branch, so nɔ branch grant nɔ de we kin tɔk se i gɛt ɔtoriti pan am.

| Udat | Wetin i kin du |
|-----|-----------------|
| **Mɛmbaship Admin** (chɔch-wayd grant) | Ɔltin: mek kɔhɔt, plan sɛshɔn, wok di intrɛs pul, admit pipul, mak atɛndans ɛn omwok, rɛkɔd di las tɛst, gradyuet di kɔhɔt |
| **Mɛmbaship Champion** (pa-branch grant) | Fɔ rid nɔmɔ. I de si in yon branch wetlis ɛn di wan dɛn we dɛn admit, ɛn i de gɛt dat branch in mɛmbaship nɔtifikeshɔn. I nɔ kin mek kɔhɔt ɔ mak ɛnitin. |
| **Fɛloship ɛn dipatmɛnt lida dɛn** | Dɛn de si di klas prɔgrɛs fɔ dɛn yon grup mɛmba nɔmɔ |
| **Platfɔm admin** | Ɔltin, lɛk ɔltɛm |
| **Ɛvribɔdi ɛls** | Luk di kɔhɔt dɛn, sho se dɛn want, ɛn fɔlo dɛn yon prɔgrɛs |

::: tip Branch Sistem Admin nɔto Mɛmbaship Admin
Bikɔs di program na chɔch-wayd, branch grant nɔ de rich am, nɔ mata omɔch branch pɔsin de admin. Dɛn fɔ gi di Mɛmbaship Admin grant klia-klia. Si [Yuza Pamishɔn dɛn](/kri/administration/permissions).
:::

## Yu nɔ kin put yusɛf insay

Dis na di pat we de sɔprayz pipul pas ɔl. Mɛmba nɔ kin put insɛf insay kɔhɔt. Di rod fɔ go in ɔltɛm na:

1. **Di mɛmba sho se i want.** Wan tap frɔm di Mɛmbaship pej. Dat de put am insay di **intrɛs pul**, we nɔ tay to ɛni kɔhɔt.
2. **Admin de admit am.** Frɔm di pul, Mɛmbaship Admin de pik pipul ɛn admit dɛn insay wan spɛshal kɔhɔt.

Di rizin we di pul nɔ tay to ɛni kɔhɔt: pɔsin kin se "yɛs, a want du dis" di sem wik we i disayd, witawt fɔ wet te dɛn plan kɔhɔt ɔ fɔ ges us wan i go ebul fɔ atɛnd.

If di pɔsin dɔn finish di klas, ɔ i dɔn gɛt wan ɛnrolmɛnt we opin, dɛn nɔ go tek di intrɛs.

### Di wetin tɛm

Wan pul ɛntri de las **180 de**. Afta dat i de laps.

Di lapsin nɔto nayt job. Dɛn de put am di sem minit we ɛnibɔdi rid ɔ rayt di pul, we min se di lis we admin de luk ɔltɛm rayt, ɛn no tɛm nɔ de we old ɛntri de luk lɛk i de laytin. Dɛn de akayv wan lapsd ɛntri sɔm wan mont afta.

Lapsd, witdrɔn, ɛn admitɛd — ɔl na fayn. If pɔsin in intrɛs laps ɛn i want kam bak, i go sho se i want bak ɛn di 180 de go stat egen.

### Fɔ admit pipul

Opin di kɔhɔt ɛn admit frɔm di wetlis. Tin dɛn fɔ no:

- Dɛn nɔ go admit if di kɔhɔt dɔn dɔn ɔ dɛn kansel am, ɔ if di ɛnrolmɛnt lɔk.
- Ɛnibɔdi we dɔn finish di klas, dɛn de tek am awt.
- Ɛnibɔdi we gɛt opin ɛnrolmɛnt insay difrɛn kɔhɔt, dɛn de flag am, dɛn nɔ de muv am kwayɛt.
- If yu admit di sem pɔsin tu tɛm, nɔtin bad nɔ de apin.
- Yu kin admit pɔsin we nɔ bin de insay di pul at ɔl, fɔ di pɔsin we sayn pan pepa na di wɛlkɔm dɛsk. Dɛn de rɛkɔd am se i nɔ kam tru di pul, so dat di tu rod dɛn de klia insay ripɔt.

Di mɛmba insɛf ɔ admin kin witdrɔ, wit rizin: i stɔp fɔ kam, i witdrɔ, i muv go ɔda ples, i push am go di nɛks kɔhɔt, ɔ ɔda tin. Pɔsin we dɔn gradyuet, dɛn nɔ kin witdrɔ am.

## Kɔhɔt dɛn

Kɔhɔt na wan ron fɔ di klas. Mek am frɔm **Mɛmbaship**, dɔn plan in sɛshɔn dɛn.

| Fil | Not dɛn |
|-------|-------|
| Nem | Yu fɔ ful am |
| Diskripshɔn | Yu nɔ nid fɔ put am |
| Stat de | Yu fɔ ful am |
| Gradyueshɔn de | Di indɔkshɔn ɔ satifiket seremoni |
| Las tɛst dɛdlayn | Yu nɔ nid fɔ put am; if yu put am, tɛst we dɛn tek afta dat nɔ de kawnt |
| Stetɔs | Plan, Aktiv, Dɔn, ɔ Kansel |
| Ɛnrolmɛnt opin | Ɔf am fɔ stɔp admishɔn witawt fɔ kansel di kɔhɔt |
| Omwok pas mak | Pan 100, 50 bay difɔlt |
| Kwiz pas mak | Pan 100, 50 bay difɔlt |
| Las tɛst pas mak | Pan 100, 50 bay difɔlt |

Di pas mak dɛn de na di kɔhɔt, so wan ron kin put in yon layn. If yu chenj pas mak leta, dat **nɔ de** mak bak di wok we dɛn dɔn mak: di pas ɔ fel de disayd ɛn dɛn sev am di minit we yu put di skɔ.

Dɛn nɔ kin dilit kɔhɔt we pɔsin stil de ɛnrol insay am. Ɛniwe di dilit na sɔft dilit; di istri de stil de.

### Sɛshɔn dɛn

Ɛvri kɔhɔt gɛt **fɔ** sɛshɔn, nɔmba 1 to 4. Dis fiks, yu nɔ kin chenj am. Ɛvri sɛshɔn de tek taytul, de, ples, ticha (yu nɔ nid fɔ put am), ɛn not dɛn.

If yu nem pɔsin as di sɛshɔn in ticha, na plan tin nɔmɔ. I nɔ de gi no pamishɔn. Na admin dɛn de mak.

## Fɔ mak di rɛjista

Opin wan sɛshɔn ɛn rɛkɔd, fɔ ɛvri pɔsin:

- Atɛnd, yɛs ɔ nɔ
- Omwok skɔ, we de mek pas ɔ fel igens di kɔhɔt in omwok pas mak
- Kwiz skɔ, we de mek pas ɔ fel igens di kɔhɔt in kwiz pas mak
- Not dɛn

Di las tɛst dɛn de rɛkɔd am wans fɔ ɛvri pɔsin, nɔto fɔ ɛvri sɛshɔn, wit di de we dɛn tek am. Di indɔkshɔn dɛn de rɛkɔd am as atɛnd ɔ nɔ atɛnd.

## Fɔ gradyuet

Gradyueshɔn gɛt get. Pɔsin redi nɔmɔ we **ɔl siks** pan dɛn ya na tru:

1. I atɛnd ɛvri sɛshɔn we dɛn bin plan
2. I pas di omwok fɔ ɛvri sɛshɔn
3. I pas di kwiz fɔ ɛvri sɛshɔn
4. I pas di las tɛst
5. I tek di las tɛst pan ɔ bifo di dɛdlayn, if di kɔhɔt gɛt wan
6. I atɛnd di indɔkshɔn

If yu tray fɔ gradyuet pɔsin we nɔ redi, Kairos nɔ go gri ɛn i go tɛl yu us wan pan di siks nɔ de yet, fɔ ɛvri pɔsin, so dat wan tɛm yu kin si udat de wet fɔ wetin.

::: tip Plan, nɔto tiori
"Ɛvri sɛshɔn" min ɛvri sɛshɔn we yu tru-tru plan. If kɔhɔt bin gɛt tu sɛshɔn nɔmɔ pan di kalɛnda, di rɛdines de aks bɔt dɛn tu nɔmɔ. Plan ɔl fɔ bifo yu stat fɔ mak.
:::

### Di ovarayd

Admin kin gradyuet pɔsin we nɔ redi, bɔt i fɔ gi rizin we dɛn rayt, ɛn dɛn de sev am pan in rɛkɔd. Yuz am fɔ di tru ej kes dɛn, lɛk pɔsin we tek sɛshɔn na ɔda branch, nɔto fɔ klia bakslog.

### Wetin gradyueshɔn de du

Gradyueshɔn de put di de we di klas dɔn pan di mɛmba in rɛkɔd. Dat wan mak na di onli signal we de mek pɔsin kɔnfam Mɛmba, ɛn na dat di Mɛmba nɔmba insay ripɔt de kawnt. Wan manyual admin ovarayd de bak pan di mɛmba rɛkɔd insɛf, fɔ old mɛmba dɛn we finish di klas lɔngtɛm bifo Kairos bin de.

## Nɔtifikeshɔn dɛn

Fɔ tɛm de we de sɛn nɔtifikeshɔn to di mɛmba in branch Mayn Pasto ɛn to dat branch in Mɛmbaship Champion dɛn:

- Pɔsin jɔyn di wetlis
- Dɛn admit pɔsin insay kɔhɔt
- Pɔsin gradyuet
- Pɔsin witdrɔ, ɔ in intrɛs laps

## Wetin mɛmba de si

Frɔm **Mɛmbaship**, witawt ɛni grant at ɔl, mɛmba kin:

- Luk di kɔhɔt dɛn ɛn dɛn sɛshɔn plan
- Sho se i want, ɛn pul am bak
- Si in yon ɛnrolmɛnt, in mak dɛn, ɛn ɛgzakli wetin lɛf bifo i kin gradyuet
- Si di de we i finish di klas, afta i dɔn finish
