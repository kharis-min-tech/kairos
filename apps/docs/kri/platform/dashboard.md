## Wan pej, we dɛn bil wit blɔk dɛn

Naw na wan sɛt blɔk, ɛn wetin yu de si dipɛnd pan di **altitud** we yu grant dɛn put yu.

| Altitud | Udat de de | Wetin dɛn de gɛt |
|----------|-------------|---------------|
| Chɔch | Platfɔm admin dɛn | Di ol chɔch in nɔmba dɛn; nɔ pɔsinal ajɛnda |
| Branch | Ɛnibɔdi we gɛt branch grant | Branch nɔmba dɛn, di branch lis, ɛn wan ajɛnda |
| Grup | Fɛloship ɛn dipatmɛnt lida dɛn | Wan ajɛnda ɛn wan lis, fɔ dɛn yon grup nɔmɔ |
| Pɔsinal | Ɔl di ɔda dɛn | Dɛn yon wik |

Di altitud de kɔmɔt frɔm kapabiliti, nɔto frɔm wan rol fil. Na dat mek fɛloship lida naw de si in fɛloship in nɔmba dɛn: bifo, i bin de fɔl to di branch vyu ɛn si branch nɔmba dɛn we nɔto fɔ am.

Wan bajj ɔnda di griytin de tɛl yu wetin lɛns yu de luk tru. Na fɔ sho nɔmɔ, ɛn i nɔ de blɔk natin.

## Di blɔk dɛn

### Pɔls

Di layn fɔ nɔmba pan tɔp, na branch altitud ɛn ɔp.

**Chɔch pɔls** de sho Branch dɛn, Ɔl di Kɔngrigeshɔn, Kɔnfam Mɛmba dɛn, ɛn Fɛloship dɛn. **Branch pɔls** de sho Ɔl di Kɔngrigeshɔn, Kɔnfam Mɛmba dɛn, Atɛndans las wik, ɛn Fɛloship dɛn.

::: tip Ɔl di kɔngrigeshɔn ɛn Kɔnfam mɛmba na tu difrɛn nɔmba
Ɔl di kɔngrigeshɔn na di ol rɔl. Kɔnfam mɛmba de kawnt di pipul dɛn we dɔn finish di [mɛmbaship klas](/kri/platform/membership) nɔmɔ. Wan branch we ɛlti kin gɛt plɛnti mɔ pan di fɔs wan dan di sɛkɔn. Si [Groth Ripɔt dɛn](/kri/analytics/growth-reports#kɔngrigeshɔn-brekdawn).
:::

Ɔnda de, Pɔls de kɛr **wɔnin** we sɔntin nid atɛnshɔn: rɛjista we nɔbɔdi nɔ tek, mɛmba dɛn we de drift, branch dɛn we de bihayn, ɔ branch we nɔ gɛt Mayn Pasto. Ɛvri wɔnin na link strɛt to di pej usay yu go fiks am.

### I nid yu

Tin dɛn we de wet pan yu fɔ tru, we dɛn kawnt ɛn link: rejistreshɔn fɔ aprov, wɔri dɛn we dɛn mak, fɔlo ɔp dɛn we dɔn du. Di wan dɛn we ɔjɛnt, dɛn mak dɛn.

Dis tek di ples fɔ wan patan usay aproval bin na nɔmba pan kad we yu fɔ notis, ɛn wɔri dɛn bin de pan pej we yu fɔ mɛmba fɔ vizit.

### Ajɛnda

Wetin de apin, insay tɛm ɔda: fɛloship mitin dɛn, sɛvis dɛn, ɛn sɛshɔn dɛn we de kam. Na grup altitud i de fɔ yu yon grup nɔmɔ.

### Grup dɛn

Na chɔch altitud, wan sɔmari pɛ branch. Ɔnda dat, wan sɔmari fɔ di grup dɛn we yu de lid.

### Rɛsɛnt aktiviti

Wan layv fid we kɔmɔt frɔm fayv rial ples: nyu rejistreshɔn, fɔm dɛn we dɛn sɛn, mɛmbaship grajueshɔn, fɛloship mitin dɛn, ɛn sol dɛn we wi rich.

### Fɔ stat

Na fɔ pipul dɛn we nɔ dɔn sɛt dɛnsɛf ɔp nɔmɔ. I de ɔfa di nɛks rial step: ful yu prɔfayl, jɔyn wan fɛloship, ɔ sho se yu want di mɛmbaship klas.

### Strik

Yu yon ron fɔ sɛvis dɛn we yu kam wan afta di ɔda.

### Di de in vas

Wan skripchɔ, we de chenj ɛvri de.
