## Di paplayn stej dɛn

Sol dɛn de muv tru fɔ stej:

| Stej | Wetin i min |
|-------|---------|
| Nyu | Dɛn jɔs kach am; no fɔlo ɔp nɔ de yet |
| De Fɔlo Ɔp | Dɛn dɔn mek kɔntakt |
| Intrɛstɛd | I de sho tru intrɛs insay di fet |
| Kɔnvat | I dɔn mek disishɔn; i redi fɔ Nyu Biliva ɛnrolmɛnt |

Wan ɔda awtkam, **Nɔ Intrɛstɛd**, de kɔmɔt pan di aktiv paplayn bɔt i de stil insay di rɛkɔd dɛn.

## Sol kad dɛn

Ɛvri kad insay di paplayn de sho:
- Di sol in nem ɛn fon nɔmba
- Di wɔka we dɛn gi am (wit in inishal)
- Di de fɔ di las kɔntakt ɔ "No fɔlo ɔp nɔ de"
- Wan stetɔs dɔt (di kɔlɔ de tɛl yu aw di fɔlo ɔp de go)

## Fɔ kach nyu sol

Klik **+ Kach Sol** fɔ ad pɔsin pan di paplayn:

| Fil | Not dɛn |
|-------|-------|
| Fɔs nem, Las nem | Yu fɔ ful dɛn |
| Fon | I gud fɔ fɔlo ɔp |
| Imel | Yu nɔ nid fɔ put am |
| Jɛnda | Yu nɔ nid fɔ put am |
| Ej rɛnj | Yu nɔ nid fɔ put am |
| Awtrich program | Link am to di program usay dɛn rich am |
| Adrɛs / Siti | Yu nɔ nid fɔ put am |
| Not dɛn | Ɛni fɔs tin we yu fɔ no |

Di sol de go insɛf to di mɛmba we kach am. Yu kin gi am to ɔda wɔka if yu nid.

## Fɔ rɛkɔd fɔlo ɔp

Opin wan sol kad ɛn ad wan fɔlo ɔp ɛntri:

- De ɛn tɛm
- Kɔntakt we: Fon Kɔl, Tɛks Mɛsej, Imel, WhatsApp, Fes-to-Fes Vizit, Ɔda
- Awtkam: I Wok, Nɔbɔdi Nɔ Ansa, Rɔng Nɔmba, Kɔl Bak Leta, Nɔ Intrɛstɛd, Intrɛstɛd
- Omɔch minit
- Not dɛn
- Nɛks fɔlo ɔp de

## Fɔ filta di paplayn

| Filta | Ɔpshɔn dɛn |
|--------|---------|
| Branch | Ɔl Branch ɔ wan branch (Admin nɔmɔ) |
| Fɛloship dɛn | Mi Fɛloship dɛn ɔ wan spɛshal wan |
| Dipatmɛnt dɛn | Mi Dipatmɛnt dɛn ɔ wan spɛshal wan |
| Wɔka | Ɛni wɔka ɔ wan spɛshal mɛmba |
| Sos | Ɔl Awtrich Program ɔ wan spɛshal program |

Sɔt bay **De we dɛn Ad am**, **Nem**, ɔ **Las Kɔntakt**.

## Fɔlo ɔp ɛlt sayn dɛn

- **Kritikal**: no kɔntakt fɔ 7+ de
- **Wach**: dɛn mek kɔntakt bɔt nɔtin nɔ de muv
- **Pan Trak**: fɔlo ɔp we nyu ɛn we de wok

## Fɔ muv go Nyu Biliva

We dɛn mak sol as **Kɔnvat**, dɛn de mek ɛnrolmɛnt insɛf insay di [Nyu Biliva](/kri/platform/new-believers) paplayn.
