# Awtrich Program dɛn

<SectionClip slug="platform/outreach" />

## Di program lis

Dɛn de sho program dɛn insay tebul wit:

| Kɔlɔm | Diskripshɔn |
|--------|-------------|
| Program Nem | Di nem fɔ di ivanjelizm ivɛnt |
| De | We di program de ron |
| Ples | Usay i de apin |
| Kɔɔdineta | Di mɛmba we gɛt di wok |
| Sol dɛn we Dɛn Rich | Omɔch sol dɛn kach pan dis ivɛnt |
| Rɛjista | Omɔch wɔka sayn ɔp |
| Stetɔs | Aktiv ɔ Dɔn |
| Rɛjistreshɔn | Opin ɔ Lɔk |
| Akshɔn dɛn | Ɛdit ɔ luk di program ditel dɛn |

Yuz di **Aktiv Program** ɛn **Pas Program** tab dɛn fɔ swich bitwin naw ɛn bifo. Sach bay program nem wit di sach ba.

## Fɔ mek program

Klik **+ Mek Program** (Lida, Pasto, ɛn Admin):

| Fil | Not dɛn |
|-------|-------|
| Program nem | Yu fɔ ful am |
| Branch | Yu fɔ ful am; i de disayd udat kin rɛjista |
| De | Yu fɔ ful am |
| Ples | Yu fɔ ful am |
| Adrɛs / Siti | Yu nɔ nid fɔ put am |
| Diskripshɔn | Yu nɔ nid fɔ put am |
| Kɔɔdineta | Link am to wan mɛmba; di pɔsin we gɛt di wok |

## Fɔ rɛjista as wɔka

Mɛmba dɛn kin rɛjista dɛnsɛf as wɔka pan ɛni aktiv program insay dɛn branch. We dɛn dɔn rɛjista, dɛn de sho pan di program in wɔka lis ɛn dɛn kin si dɛn nɛks awtrich wok dɛn frɔm dɛn prɔfayl.

## Fɔ kach sol dɛn

Afta program, kɔɔdineta ɛn lida dɛn de rɛkɔd di sol dɛn we dɛn rich bay fɔ link di sol kach rɛkɔd dɛn to di program. Ɛvri sol we dɛn kach pan di ivɛnt de sho insay di [Sol Paplayn](/kri/platform/souls-pipeline) ɛn i de ad to di **Sol dɛn we Dɛn Rich** kawnt.

## Udat kin manej awtrich

| Akshɔn | Mɛmba | Lida | Pasto | Admin |
|--------|--------|--------|--------|-------|
| Si di program dɛn | Yɛs (in yon branch) | Yɛs | Yɛs | Yɛs |
| Rɛjista as wɔka | Yɛs (in yon branch) | Yɛs | Yɛs | Yɛs |
| Mek program | Nɔ | Yɛs (program dɛn we i de kɔɔdinet) | Yɛs | Yɛs |
| Chenj program | Nɔ | Yɛs (in yon program) | Yɛs | Yɛs |
| Si ɔl di wɔka rɛjistreshɔn | Nɔ | Yɛs (in yon program) | Yɛs | Yɛs |
