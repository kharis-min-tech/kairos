## Ministri tayp dɛn

Dɛn de mek dipatmɛnt frɔm wan **katalog** fɔ ministri tayp, nɔto bay fɔ rayt nem, so dat di sem ministri min di sem tin insay ɛvri branch. Di katalog na lis we dɛn de manej; di drɔpdawn pan di mek fɔm na di ɔtoriti fɔ yu chɔch ɔltɛm.

Dɛn ya na di tayp dɛn we Kairos kam wit:

| Ministri | Wetin i min |
|----------|-------------|
| Admin | Sɛvis-de rɛjista ɛn fɔs-tɛm kach |
| Kwaya | Myuzik ministri ɛn wɔship |
| Dizayn | Grafiks ɛn kriativ wok |
| Drama | Drama ɛn stej pafɔmans |
| Fɔlo-Ɔp Tim | De kɔntakt fɔs-tɛm pipul afta dɛn vizit, ɛn mɛmba dɛn we nɔ de na fɛloship ɔ dipatmɛnt |
| Ɔspitaliti | Chɔp, drink ɛn ges kia |
| Ost Tim | De wɛlkɔm fɔs-tɛm ges dɛn pan di de |
| Nyu Biliva dɛn | Kia ɛn disaypulship fɔ nyu kɔnvat dɛn |
| Prɔdɔkshɔn | Stej prɔdɔkshɔn ɛn layt |
| Sankchuari Kipa dɛn | Fɔ klin ɛn redi di ples |
| Soshal Midia | Ɔnlayn prɛzɛns ɛn kɔntɛnt |
| Sawnd | Ɔdio injinirin ɛn miksin |
| Usha dɛn | Dɔ, sidɔm ples ɛn ɔda |
| Wɛlfɛa | Pastɔral kia ɛn ɛp |

::: tip Ost Tim ɛn Fɔlo-Ɔp Tim nɔto di sem wok
Ost Tim de wɛlkɔm pɔsin we i de insay di bildin. Fɔlo-Ɔp Tim de kɔntakt am afta, ɛn dɛn de wok di lis fɔ mɛmba dɛn we nɔ de na ɛni grup yet. Na sɛpret dipatmɛnt pɔposli, bikɔs na sɛpret shift wit sɛpret skil. Si [Fɔlo ɔp dɛn](/kri/platform/follow-ups).
:::

Yuz di **Ɔl Branch** drɔpdawn fɔ filta bay branch we yu de ron plɛnti ples.

## Dipatmɛnt kad dɛn

Ɛvri kad de sho:
- Di dipatmɛnt nem ɛn branch
- Di lida in nem
- Omɔch mɛmba de aktiv
- Diskripshɔn
- **Diaktivet** bɔtin (Pasto ɛn Admin nɔmɔ)
- **Pɛndin** bajj if jɔyn rikwɛst de wet fɔ aproval

| Ministri tayp | Pik frɔm di lis we de ɔp de |
| Branch | Yu fɔ ful am |
| Lida | Yu fɔ ful am; i fɔ na mɛmba insay di branch |
| Dɛpyuti | Yu nɔ nid fɔ put am; i fɔ difrɛn frɔm di lida |
| Stat de | Tide bay difɔlt |
| Diskripshɔn | Yu nɔ nid fɔ put am |

Ɛvri branch kin gɛt wan aktiv dipatmɛnt fɔ ɛvri tayp.

## Fɔ jɔyn wan dipatmɛnt

Mɛmba kin aks fɔ jɔyn wan dipatmɛnt frɔm dɛn prɔfayl ɔ di dipatmɛnt pej. Di rikwɛst de go to di dipatmɛnt lida fɔ aprov. Mɛmba kin de na **tu dipatmɛnt** nɔmɔ at a tɛm. Di sistem de wɔn di lida if di mɛmba dɔn gɛt tu, bɔt admin kin ovarayd am.

## Jɔyn rikwɛst dɛn we de wet

We wan dipatmɛnt kad de sho **pɛndin** bajj, di dipatmɛnt lida gɛt jɔyn rikwɛst dɛn we i nɔ aprov yet.

## Dipatmɛnt mɛmba lis

Lida dɛn kin si dɛn ful dipatmɛnt lis wit mɛmba kɔntakt, di de we dɛn jɔyn, ɛn fɔlo ɔp not dɛn.

## Udat kin ron dipatmɛnt

| Akshɔn | Mɛmba | Lida | Pasto | Admin |
|--------|--------|--------|--------|-------|
| Si di dipatmɛnt lis | Yɛs | Yɛs | Yɛs | Yɛs |
| Mek dipatmɛnt | Nɔ | Nɔ | Yɛs | Yɛs |
| Diaktivet dipatmɛnt | Nɔ | Nɔ | Yɛs | Yɛs |
| Aprov jɔyn rikwɛst | Nɔ | In yon nɔmɔ | Yɛs | Yɛs |
| Si di mɛmba lis | Nɔ | In yon nɔmɔ | Yɛs | Yɛs |
| Rɛkɔd fɔlo ɔp not | Nɔ | In yon nɔmɔ | Yɛs | Yɛs |
