## Di fɔm dɛn we de

| Fɔm | Wetin i de du |
|------|---------|
| Fɔs-Tɛm Vizita | Wɛlkɔm vizita ɛn tek dɛn ditel fɔ fɔlo ɔp |
| Nyu Biliva Klas | Rɛjista pɔsin we ansa alta kɔl insay di disaypulship program |
| Baptizm | Tek rikwɛst fɔ baptayz |
| Tɛstimoni | Sheb tɛstimoni bɔt wetin Gɔd dɔn du |
| Bebi Nemin | Aks fɔ bebi nemin seremoni |
| Bebi Dedikeshɔn | Aks fɔ bebi dedikeshɔn |

Klik **Opin fɔm →** pan ɛni kad fɔ opin dat fɔm.

::: warning Admin ɛn Pasto nɔmɔ
Ɔl di siks fɔm na fɔ Admin ɛn Pasto nɔmɔ. Lida dɛn we de insay di Admin dipatmɛnt kin rivyu di frɔnt dɛsk fɔm dɛn bak. Rɛgyula mɛmba nɔ kin go pan di Fɔm pej.
:::

## Fɔm we dɛn Sɛn

Klik **Sɛn dɛn** ɔnda di Administreshɔn sɛkshɔn fɔ rivyu ɔl di fɔm dɛn we dɛn kach.

### Fɔ filta di fɔm dɛn

| Filta | Ɔpshɔn dɛn |
|--------|---------|
| Fɔm tayp | Ɔl fɔm, Fɔs-Tɛm Vizita, Nyu Biliva Klas, Baptizm, Tɛstimoni, Bebi Nemin, Bebi Dedikeshɔn |
| Stetɔs | Ɔl stetɔs, De wet, Rivyu, Dɔn du |
| Frɔm / To | De rɛnj |

### Fɔ ɛkspɔt di fɔm dɛn

Klik **Ɛkspɔt CSV** fɔ dawnlod ɔl di fɔm dɛn we yu filta as sprɛdshit. I gud fɔ fɔlo ɔp wok we de apin awtsay di sistem.

## Dɔman Vizita dɛn

Klik **Dɔman vizita** fɔ akayv wans wan ɔl di old kɔntakt shɛl dɛn we fɔm mek: pipul we kam tru vizita ɔ alta kɔl fɔm bɔt dɛn nɔ du nɔtin afta. Dis de kip di mɛmba dayrɛktri klin witawt fɔ dilit ɛni rɛkɔd fɔ ɔltɛm.

## Aw di fɔm dɛn tay to ɔda pat dɛn

- **Nyu Biliva Klas** fɔm → de mek ɛnrolmɛnt insay di [Nyu Biliva](/kri/platform/new-believers) paplayn insɛf
- **Fɔs-Tɛm Vizita** fɔm → de mek kɔntakt rɛkɔd fɔ fɔlo ɔp
- **Baptizm** fɔm → de mek rikwɛst we de sho insay di admin rivyu kyu
- **Bebi Nemin / Dedikeshɔn** → de mek rikwɛst fɔ di admin fɔ plan
