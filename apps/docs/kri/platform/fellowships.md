# Fɛloship dɛn

<SectionClip slug="platform/fellowships" />

Fɛloship na di smɔl grup dɛn insay ɛvri branch. Kairos de sɔpɔt plɛnti fɛloship tayp, wan map vyu fɔ fɛn grup dɛn we nia yu, ɛn ful mitin ɛn atɛndans trakin.

## Fɛloship tayp dɛn

| Tayp | Wetin i min |
|------|-------------|
| K-Groups | Jenaral smɔl grup Baybul stɔdi |
| Kharis Express | Fɛloship fɔ yɔng wok pipul |
| New Breeds | Fɛloship fɔ put nyu mɛmba dɛn insay |
| KOC | Kharis on Campus |
| KOC Colleges | Kharis on Campus Colleges |

Yuz di tayp tab dɛn na di tɔp fɔ filta bay tayp, ɔ yuz di **Ɔl Branch** drɔpdawn fɔ filta bay branch.

## Fɛloship kad dɛn

Ɛvri kad de sho:
- Di fɛloship nem ɛn tayp bajj
- Di branch nem
- Diskripshɔn
- Mitin skɛjul (fɔ ɛgzampul «Ɛvri Frayde, 6:30 PM»)
- **Diaktivet** bɔtin (Pasto ɛn Admin nɔmɔ)

## Fɛn wan fɛloship pan di map

Klik **Fɛn pan Map** fɔ opin di map vyu. Dɛn de put di fɛloship dɛn bay dɛn branch ples, wit kɔlɔ bay tayp.

### Di map pɔpɔp

Klik ɛni maka pan di map fɔ si di fɛloship nem, di branch, ɛn we tɛm di nɛks mitin de.

### Di fɛloship we nia yu

Luk wit postkod ɔ kɔntri fɔ fɛn di wan we nia yu. Kairos de sho:

- Di distans na km
- Aw lɔng fɔ waka, bɔs, kia, ɛn trɛn
- Link fɔ gɛt dairɛkshɔn tru Maps ɔ Waze
- Di fɛloship tayp dɛn we de na dat ples

| Fil | Not dɛn |
|-------|-------|
| Fɛloship nem | Yu fɔ ful am, ɛn i fɔ difrɛn insay di branch |
| Branch | Yu fɔ ful am |
| Fɛloship tayp | K-Groups, Kharis Express, New Breeds, KOC, KOC Colleges |
| Lida | Yu fɔ ful am; i fɔ na mɛmba we dɔn de |
| Ko-lida | Yu nɔ nid fɔ put am |
| Mitin skɛjul | fɔ ɛgzampul «Ɛvri Frayde, 6:30 PM» |
| Diskripshɔn | Yu nɔ nid fɔ put am |

## Fɛloship stat dɛn

Di tɔp rayt pan di Fɛloship pej de sho omɔch fɛloship de ɔltugɛda ɛn omɔch de wok naw.

## Udat kin si wetin

| Akshɔn | Mɛmba | Lida | Pasto | Admin |
|--------|--------|--------|--------|-------|
| Si di fɛloship lis | Yɛs | Yɛs | Yɛs | Yɛs |
| Yuz di map vyu | Yɛs | Yɛs | Yɛs | Yɛs |
| Mek fɛloship | Nɔ | Nɔ | Yɛs | Yɛs |
| Diaktivet fɛloship | Nɔ | Nɔ | Yɛs | Yɛs |
| Ron di fɛloship mɛmba lis | Nɔ | In yon nɔmɔ | Yɛs | Yɛs |
| Rɛkɔd mitin atɛndans | Nɔ | In yon nɔmɔ | Yɛs | Yɛs |
