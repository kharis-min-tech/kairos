# Prayvesi Notis

**I stat pan 23 Julay 2026 · Vɔshɔn 2026-07-v1**

::: tip Transleshɔn fɔ ɛp yu
<!-- i18n-allow-en -->
Dɛn mek dis transleshɔn fɔ ɛp yu nɔmɔ. If ɛnitin difrɛn, na di [Inglish vɔshɔn](/legal/privacy) de ron.
:::

Dis notis de ɛksplen aw Kharis Church ("wi", "di chɔch") de tek ɛn yuz yu pɔsnal data we yu de yuz Kairos, wi insay chɔch administreshɔn platfɔm. Dɛn rayt am fɔ fɔlo di UK Jɛnɛral Data Prɔtɛkshɔn Rɛgyuleshɔn (UK GDPR) ɛn di Data Prɔtɛkshɔn Akt 2018.

Kharis Church na di data kɔntrola fɔ di pɔsnal data we Kairos de prɔsɛs. If yu gɛt kwɛshɔn bɔt dis notis, ɔ if yu want yuz ɛni rayt we de dɔng ya, kɔntakt wi na [privacy@kharis.org](mailto:privacy@kharis.org).

## 1. Udat dis notis de tɔk bɔt

Dis notis na fɔ Kharis Church mɛmba dɛn we mek akawnt insay Kairos, fɔ pipul dɛn we wi lida de put dɛn info insay Kairos (fɔ ɛgzampul fɔs-tɛm vizita we dɛn kach pan wɛlkɔm fɔm, ɔ pikin dɛn we dɛn parɛnt gi di info fɔ dɛn), ɛn fɔ ɛnibɔdi we sɛn info tru pɔblik Kairos fɔm.

## 2. Us pɔsnal data wi de tek

### 2.1 Info we yu gi wi we yu sayn ɔp

- Ful nem (fɔs, midul, las) ɛn ɛni onorifik we yu want
- Imel adrɛs ɛn fon nɔmba
- De we yu bɔn ɛn jɛnda
- Om adrɛs ɛn (if yu want) sɛkɔn adrɛs
- Di Kharis Church branch we yu de go
- Ɛmajɛnsi kɔntakt nem, aw una tay, ɛn fon nɔmba
- Paswɔd (wi de sev am as wan-we kriptografik ash nɔmɔ)

### 2.2 Info we yu kin ad leta

- Prɔfayl pikchɔ
- Marid stetɔs, wok, chɔch bakgrawnd bifo
- Nɔtifikeshɔn prɛfrɛns

### 2.3 Info we yu chɔch aktiviti de mek

- Sɛvis ɛn fɛloship atɛndans rɛkɔd
- Fɛloship grup mɛmbaship ɛn ɛni lidaship rol we yu ol
- Dipatmɛnt mɛmbaship, rota asaynmɛnt, ɛn yunifɔm sayz
- Nyu biliva disaypulship paplayn stej, if i tɔch yu, wit di mɛnto sɛshɔn not dɛn we yu mɛnto rayt
- Fɔm dɛn we yu sɛn (fɔ ɛgzampul: baptizm aplikeshɔn, tɛstimoni, alta-kɔl ansa, bebi dedikeshɔn, diklaratif fɔm)
- Prea rikwɛst, fɔlo ɔp not, ɔ sefgadin not we lida rɛkɔd fɔ pastɔral kia
- Rɛkɔd fɔ di kɔnsɛnt we yu gi ɔ pul, ɛn di vɔshɔn fɔ dis notis ɛn wi Tɛms ɛn Kɔndishɔn we yu aksɛpt

### 2.4 Tɛknikal info

- Sayn-in taym, sɛshɔn tokin, ɛn di brawza we yu yuz
- IP adrɛs ɛn smɔl divays info, we wi de yuz fɔ protɛkt yu akawnt frɔm pipul we nɔ gɛt rayt nɔmɔ
- Ɛra ripɔt we de mek insɛf if pat pan Kairos fel wayl yu de yuz am

### 2.5 Spɛshal katigɔri ɛn sefgadin data

We fɔm aks yu fɔ tɔk bɔt yu ɛlt, disabiliti, pikin we yu de kia, ɔ sefgadin kɔnsɛn, wi de kia fɔ dat info spɛshal wan. Wi de tek am nɔmɔ we i nid fɔ di pastɔral ɛn sefgadin wok fɔ di chɔch, ɛn na lida dɛn we gɛt lɔfɔl rizin fɔ si am kin si am.

## 3. Wetin mek wi de yuz yu data, ɛn wi lɔfɔl bes

Ɔnda UK GDPR, wi kin prɔsɛs yu data nɔmɔ if wi gɛt lɔfɔl bes. Wi de stan pan dɛn bes ya:

| Wetin fɔ | Lɔfɔl bes |
|---------|-------------|
| Fɔ administa chɔch mɛmbaship, fɔ lɛ yu sayn in, ɛn fɔ kɔntakt yu bɔt sɛvis ɛn fɛloship we yu de insay | Di chɔch in lijitimet intrɛs fɔ kia fɔ in mɛmba dɛn |
| Fɔ rɛkɔd atɛndans, fɔlo disaypulship prɔgrɛs, ɛn kɔɔdinet rota | Di chɔch in lijitimet intrɛs fɔ ron sɛvis ɛn ministri |
| Pastɔral kia, prea fɔlo ɔp, ɛn sefgadin fɔ pipul we wik (wit pikin ɔnda 16) | Lijitimet intrɛs, ɛn usay i tɔch, wi ligal dyuti ɔnda sefgadin lɔ |
| Fɔ sɛn yu nyuzlɛta, ivɛnt invayt, ɔ awtrich mɛsej we yu nɔ fɔ gɛt | Yu ɛksplisit kɔnsɛnt |
| Fɔ protɛkt Kairos frɔm frɔd ɛn abyuz, ɛn fɔ kip ɔdit lɔg | Lijitimet intrɛs fɔ kip platfɔm we sef |

Wi nɔ de yuz yu data fɔ ɔtomatik disishɔn we go afɛkt yu big wan, ɛn wi nɔ de sɛl yu data to ɛnibɔdi.

## 4. Udat wi de shɛr yu data wit

Yu data de sho insay Kharis Church to lida dɛn we dɛn rol want am. Di akses tay so dat lida de si di data fɔ di pipul ɛn di pat dɛn we i gɛt rɛsponsibiliti fɔ nɔmɔ.

Wi de shɛr data wit dɛn ɔda kɔmpani ya we de ɛp wi fɔ ron Kairos:

- **Cloudflare, Inc.**: de os di Kairos websayt, aplikeshɔn sava, databes getwe, ɛn imej stɔrej
- **PlanetScale, Inc.**: de ron di Postgres databes we sev yu mɛmba rɛkɔd. Dɛn de sev di data na di UK / EEA
- **Amazon Web Services, Inc.**: de sɛn trɛnzakshɔnal imel. Rijɔn: EU (London / Frankfurt)
- **Sentry, Inc.**: de gɛt ɛra ripɔt we Kairos fel, so dat wi kin fɛn ɛn fiks prɔblɛm

Dɛn provayda ya na data prɔsɛsa: dɛn de prɔsɛs yu data ɔnda wi instrɔkshɔn nɔmɔ, ɛn kɔntrakt tay dɛn fɔ protɛkt am.

Wi kin gi data bak usay di lɔ se wi fɔ du am, fɔ ɛgzampul fɔ sefgadin invɛstigeshɔn, kot ɔda, ɔ rikwɛst frɔm UK rɛgyuleta.

## 5. Omɔch tɛm wi de kip yu data

| Data tayp | Omɔch tɛm |
|-----------|-------------|
| Aktiv mɛmba rɛkɔd | As lɔng as yu de na mɛmba |
| Akayv mɛmba rɛkɔd | Te 6 ia afta yu lɛf |
| Rɛkɔd bɔt pikin ɔnda 16 | Fɔlo wi sefgadin pɔlisi |
| Atɛndans rɛkɔd | 3 ia, de rol |
| Kɔnsɛnt rɛkɔd | Di layf fɔ di akawnt plɔs 6 ia |
| Sayn-in lɔg ɛn ɛra ripɔt | Te 90 de, dɔn dɛn dilit insɛf |

## 6. Yu rayt dɛn

Ɔnda UK GDPR, yu gɛt rayt fɔ:

- **Si** yu pɔsnal data ("sɔbjɛkt akses rikwɛst")
- **Fiks** data we nɔto tru ɔ we nɔ ful
- **Pul** yu data ("di rayt fɔ dɛn fɔgɛt yu"), ɛksɛpt usay wi fɔ kip am fɔ sefgadin ɔ ligal rizin
- **Limit** aw wi de prɔsɛs yu data wayl kwɛshɔn de wok
- **Pɔtabiliti**: gɛt mashin-ridabul ɛkspɔt fɔ di data we yu gi wi
- **Ɔbjɛkt** to prɔsɛsin we wi de du bes pan wi lijitimet intrɛs
- **Pul yu kɔnsɛnt** ɛni tɛm, usay wi bin stan pan kɔnsɛnt

Fɔ yuz ɛni pan dɛn rayt ya, imel wi na [privacy@kharis.org](mailto:privacy@kharis.org). Wi go ansa insay wan kalɛnda mont.

If yu biliv se wi andul yu data bad we, yu kin kɔmplen to di UK Infɔmeshɔn Kɔmishɔna Ɔfis pan [ico.org.uk](https://ico.org.uk). Wi go beg yu fɔ tɛl wi fɔs so dat wi kin fiks am.

## 7. Pikin ɛn yɔng pipul

Kharis Church de tek pikin sefgadin siriɔs. If yu ɔnda 16, aks parɛnt ɔ gadian fɔ ful di Kairos fɔm dɛn fɔ yu. Na parɛnt ɔ di sefgadin lida we dɛn pik de mek ɛn manej pikin rɛkɔd, ɛn na lida dɛn we dɛn rol want am nɔmɔ kin si am insay Kairos.

## 8. Kuki ɛn trakin

Kairos de yuz wan fɔs-pati kuki nɔmɔ fɔ kip yu sayn in wayl yu de yuz am. Wi nɔ de yuz advatayzin kuki, wi nɔ de ron tɔd-pati analitiks we de trak yu akrɔs di wɛb, ɛn wi nɔ de shɛr aw yu de yuz am wit maketin platfɔm.

## 9. Sikyɔriti

Dɛn de sev paswɔd as wan-we kriptografik ash ɛn nɔbɔdi nɔ kin rid dɛn, wi insɛf. TLS de protɛkt data we de muv. Rol-bes pamishɔn de get di Kairos administreshɔn ɛn dɛn de kip ɔdit lɔg.

## 10. Chenj pan dis notis

We wi mek big chenj pan dis notis, wi go put nyu vɔshɔn ɛn aks yu fɔ rid ɛn aksɛpt am di nɛks tɛm yu sayn in. Smɔl tayp mistek wi kin fiks witawt aks yu.
