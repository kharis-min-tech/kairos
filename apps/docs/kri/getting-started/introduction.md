# Intrɔdɔkshɔn

Wɛlkɔm to di Kairos dɔkyumɛnteshɔn. Dis gayd kɔva ɔltin we yu fɔ no bɔt aw fɔ yuz di Kairos chɔch adminstreshɔn sistem, if na chɔch mɛmba yu de, dipatmɛnt lida, pasto, ɔ sistem adminstretɔ.

## Udat dis de fɔ?

Wetin yu de si insay Kairos kɔmɔt frɔm di pamishɔn dɛn we de pan yu akawnt, nɔto frɔm wetin dɛn de kɔl yu. Fɔ tru, aw almos ɛvribɔdi de yuz am de fɔl insay wan pan dɛn fo we ya:

- **Mɛmba dɛn**: Si yu yon prɔfayl, yu atɛndans, yu fɛloship dɛn, aw yu de go na klas, ɛn sɛn fɔm dɛn.
- **Lida dɛn**: Ron yu yon dipatmɛnt ɔ fɛloship, rɛkɔd fɔlo ɔp dɛn, ɛn rɛkɔd atɛndans.
- **Pasto dɛn**: Yu si ɛn yu kɔntrol ɔltin we de insay di branch we dɛn gi yu.
- **Admin dɛn**: Yu gɛt akses to ɔl di branch dɛn, ɔl di rijɔn dɛn, ɛn di sistem sɛtin dɛn.

Dɛn na jɔs shɔt we fɔ tɔk, ɛn wi de yuz dɛn ɔlsay insay dis dɔkyumɛnteshɔn. Dɛn nɔto rol dɛn we dɛn kin gi yu. Kairos de kip tu sistem rol nɔmɔ, `admin` ɛn `member`, ɛn ɔl di ɔda tin dɛn kɔmɔt frɔm **grant dɛn**: wan rol we dɛn nem, we dɛn tay to wan branch, wan fɛloship, wan dipatmɛnt, ɔ di ol chɔch. [Rol ɛn Pamishɔn dɛn](/kri/getting-started/roles-permissions) sho aw dɛn shɔt we ya mach wit di rial tin.

## Aw fɔ yuz dis dɔkyumɛnteshɔn

- If yu nyu, stat wit [Wetin na Kairos?](/kri/getting-started/what-is-kairos) ɛn [Di Mayn Tin Dɛn](/kri/getting-started/core-concepts).
- If na fɔs tɛm yu de sɛt ɔp wan chɔch, go na [Yu Fɔs Chɔch](/kri/getting-started/your-first-church).
- If yu want fɔ no udat kin du wetin, si [Rol ɛn Pamishɔn dɛn](/kri/getting-started/roles-permissions).
- Fɔ wan spɛshal fichɔ, yuz di **Platfɔm** sɛkshɔn na di saydba.

## Wetin Kairos kɔva

| Mɔjul | Wetin i de du |
|--------|-------------|
| Branch ɛn Rijɔn dɛn | Ron di chɔch ples dɛn ɛn aw dɛn grup bay ples |
| Mɛmba dɛn | Ful mɛmba dairɛktri, prɔfayl dɛn, aproval dɛn, CSV impɔt/ɛkspɔt |
| Mɛmbaship Klas dɛn | Di fo-wik klas, di intrɛst lis, di koɔt dɛn, di mak dɛn, ɛn grajueshɔn |
| Fɛloship dɛn | K-Groups, Kharis Express, New Breeds, ɛn mɔ, wit map vyu |
| Dipatmɛnt dɛn | Ministri tim dɛn wit mɛmba lis, rota, ɛn rikrutmɛnt |
| Atɛndans | Sɛvis chɛk-in, sɛf chɛk-in wit QR kod, ɛn fɛloship mitin rɔl dɛn |
| Fɔlo ɔp ɛn Wɔri dɛn | Pastɔral kɔntakt rɛkɔd dɛn, di fɔs-tɛm ɛn no-grup lis dɛn, ɛn di wɛlfɛa ɛn sefgadin inbɔks dɛn |
| Awtrich | Ɛvanjelizm program dɛn, sol kach, ɛn fɔlo ɔp |
| Nyu Biliva dɛn | Disaypulship paiplain frɔm alta kɔl sote go jɔyn dipatmɛnt |
| Fɔm dɛn | Fɔs-tɛm vizitɔ, baptizm, tɛstimoni, pikin nem-gi, ɛn mɔ |
| Sol Dashbɔd | Analitiks pan di sol paiplain ɛn di kɔnvɛshɔn fɔnul |
| Ripɔt ɛn Analitiks | Groth, atɛndans, ɛngejmɛnt, ɛn awtrich mɛtriks dɛn |
| Prɔfayl ɛn Sɛtin dɛn | Pɔsinal infɔmeshɔn, sikyuriti, ɛn aw yu want am fɔ luk |
