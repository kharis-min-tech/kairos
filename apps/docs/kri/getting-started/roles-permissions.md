# Rol ɛn Pamishɔn dɛn

<SectionClip slug="getting-started/roles-permissions" />

Wetin yu kin si ɛn du insay Kairos, na di **grant** dɛn pan yu akawnt de disayd am, nɔto job taytul. Dɛn de sɛt yu pamishɔn we dɛn mek yu akawnt ɛn dɛn de wok frɔm yu nɛks sayn in.

## Di wan tin fɔ ɔndastand fɔs

Kairos de sev tu sistem rol nɔmɔ: `admin` ɛn `member`. Ɛvribɔdi we nɔ de na di smɔl platfɔm tim na `member`, ivin di Sinio Pasto.

Tru ɔtoriti de kam frɔm **grant**: wan nem rol bɔndul we tay to wan branch, wan fɛloship, wan dipatmɛnt, ɔ di ful chɔch. If yu ol Fɛloship Lida grant fɔ Grace K-Group, yu kin ron Grace K-Group. If yu nɔ ol nɔtin, yu kin manej yu yon prɔfayl. If yu ol plɛnti grant, yu gɛt ɔl, ɛvri wan insay in yon bawndri.

## Di fɔ shep fɔ akses

Almos ɛvribɔdi insay chɔch de fɔdɔm insay wan pan fɔ patan. Di rɛst fɔ dis dokyumɛnteshɔn de yuz dɛn lebul ya as shɔtkɔt, ivin insay di "udat kin du wetin" tebul pan ɛvri pej.

| Lebul | Wetin i tru-tru min | Rich |
|-------|-----------------------|-------|
| **Mɛmba** | No grant | In yon data nɔmɔ |
| **Lida** | Fɛloship Lida, Dipatmɛnt Lida, ɔ Dipatmɛnt Dɛpyuti grant | Di grup we nem pan di grant, ɛn nɔtin pas dat |
| **Pasto** | Branch Sistem Admin ɔ Branch Data Admin grant | Wan branch |
| **Admin** | `systemRole` we na `admin` | Ɔltin, insay ɛvri branch |

Fɔ di ful katalog fɔ grant, wit di chɔch-wayd wan dɛn we nɔ fit nɔn pan dɛn fɔ shep, si [Yuza Pamishɔn dɛn](/kri/administration/permissions).

## Mɛmba

Ɛvribɔdi de stat ya. Afta i rɛjista ɛn dɛn aprov am, mɛmba kin:

**I kin du:**
- Si ɛn ɛdit in yon prɔfayl (nem, kɔntakt ditel, pikchɔ, ɛmajɛnsi info)
- Si in yon mɛmbaship stetɔs ɛn om branch
- Si us dipatmɛnt ɛn fɛloship i de na dɛn
- Si in yon atɛndans istri pan **Mi Atɛndans**
- Sɛn fɔm: Fɔs-Tɛm Vizita, Nyu Biliva Klas, Baptizm, Tɛstimoni, Bebi Nemin, Bebi Dedikeshɔn
- Luk di mɛmbaship klas kɔhɔt dɛn ɛn sho se i want jɔyn wan
- Aks fɔ jɔyn fɛloship, dipatmɛnt, ɔ awtrich program insay in branch
- Rɛjista as wɔka pan awtrich program
- Ɛkspɔt in yon data, ɛn aks fɔ dilit in akawnt, frɔm Sɛtin

**I nɔ kin du:**
- Si ɔda mɛmba in prɔfayl ɔ data
- Manej ɛni grup, fɛloship, ɔ dipatmɛnt
- Aprov rikwɛst ɔ du admin wok
- Opin di Mɛmba dayrɛktri, di fɔlo ɔp kyu, ɔ di Kɔnsɛn inbɔks

::: tip Pɛndin mɛmba dɛn
Pɛndin mɛmba (we rɛjista bɔt dɛn nɔ aprov am yet) kin si in yon prɔfayl nɔmɔ te sɔmbɔdi we gɛt aproval rayt insay in branch aprov di akawnt.
:::

## Lida

Lida na pɔsin we dɛn nem as lida, ko-lida, ɔ dɛpyuti fɔ wan grup. Na we dɛn nem am pan di grup de mek di grant; nɔtin nɔ de fɔ asayn bay an. In akses tay tayt to dat grup. Lida we nɔ gɛt grup gɛt di sem akses lɛk mɛmba.

**I kin du:**
- Si ɛn manej di mɛmba lis fɔ in spɛshal dipatmɛnt ɔ fɛloship
- Aprov ɔ rifyuz jɔyn rikwɛst fɔ in grup
- Rɛkɔd mitin atɛndans ɛn mek mitin
- Rɛkɔd fɔlo ɔp pan mɛmba dɛn insay in grup
- Si mɛmba kɔntakt ditel insay in grup
- Mek ɛn chenj awtrich program dɛn we i de kɔɔdinet

**Nyu Biliva ɛn Mɛmbaship vizibiliti:**
- Fɛloship ɔ dipatmɛnt lida de si di Nyu Biliva ɛn mɛmbaship klas prɔgrɛs fɔ **in yon pipul**, nɛro bay udat de insay in grup nɔto bay branch

**Ripɔt:**
- Data fɔ in grup mɛmba nɔmɔ, nɔto di ful branch

**I nɔ kin du:**
- Go pan data awtsay in grup
- Mek branch, aprov mɛmba rɛjistreshɔn, ɔ gi grant
- Si ɔda dipatmɛnt ɔ fɛloship mɛmba lis
- Rid di wɛlfɛa ɔ sefgadin inbɔks

## Pasto

"Pasto" ya min pɔsin we ol branch grant. Tu kayn de ɛn di difrɛns impɔtant.

**Branch Sistem Admin** na di branch in pamishɔn kikipa:
- Ɔltin we Branch Data Admin kin du, plɔs
- Gi ɛn pul Branch Sistem Admin insay in yon branch
- Put ɔ ɛn branch lidaship (Mayn Pasto, Minista)
- Rid di branch in wɛlfɛa inbɔks

**Branch Data Admin** na branch wok witawt di ki dɛn:
- Si ɛn manej ɔl di mɛmba akrɔs in branch
- Aprov nyu mɛmba rɛjistreshɔn
- Diaktivet ɛn riaktivet mɛmba
- Impɔt ɛn ɛkspɔt mɛmba data wit CSV
- Mek ɛn manej ɔl di fɛloship ɛn dipatmɛnt insay in branch
- Mek awtrich program fɔ in branch
- Rɛkɔd atɛndans fɔ sɛvis ɛn fɛloship mitin
- Wok di fɔs-tɛm, nɔ-grup, ɛn du-naw fɔlo ɔp kyu
- Si ɛn ɛkspɔt ɔl di fɔm tayp, ɛn manej dɔman vizita
- Go pan branch-lɛvul ripɔt: mɛmba gro, atɛndans trɛnd, fɛloship aktiviti, nyu biliva paplayn

**Nɔn pan dɛn nɔ kin:**
- Go pan data frɔm ɛni ɔda branch
- Mek, ɛdit, ɔ diaktivet branch
- Mek pɔsin tɔn platfɔm admin
- Si chɔch-wayd analitiks akrɔs ɔl branch
- Administa di mɛmbaship klas program, we na chɔch-skop

::: warning Sefgadin nɔ de insay
Nɔn pan di tu branch grant nɔ kɛr sefgadin say. Di branch in **Mayn Pasto** de gɛt am insɛf bikɔs i ol dat ɔfis, ɛn **Sefgadin Lida** de gɛt am bay grant. Minista we ol di sem Branch Sistem Admin grant lɛk di Mayn Pasto nɔ de si di sefgadin kyu. Si [Yuza Pamishɔn dɛn](/kri/administration/permissions#di-grant-we-de-kam-insɛf-branch-pasto).
:::

## Admin

Platfɔm admin gɛt ful akses we nɔtin nɔ de stɔp. Ɛvri kapabiliti chɛk de rityɔn tru fɔ dɛn, insay ɛvri branch. Dis na brek-glas akses fɔ di smɔl tim we de ron di sistem, nɔto sayn fɔ sinioriti.

**Dɛn kin du:**
- Mek ɛn manej branch ɛn rijɔn
- Gi ɛn pul grant fɔ ɛni mɛmba insay ɛni branch
- Manej mɛmba akrɔs ɔl branch
- Si chɔch-wayd analitiks ɛn ron krɔs-branch ripɔt
- Administa di mɛmbaship klas program
- Manej aproval kyu akrɔs ɔl branch
- Sɛt sistem-lɛvul sɛtin we nɔbɔdi ɛls nɔ kin tɔch

---

## Chɔch-wayd grant dɛn

Tu grant nɔ tay to nɔbɔdi in branch, bikɔs wetin dɛn kɔva na chɔch-wayd:

| Grant | Rich |
|-------|-------|
| **Mɛmbaship Admin** | Di ful mɛmbaship klas program: kɔhɔt, sɛshɔn, di intrɛs pul, admishɔn, makin, gradyueshɔn. Kɔhɔt na chɔch-wayd, so no branch grant nɔ kin tɔk se i gɛt ɔtoriti pan wan. |
| **Sefgadin Ɛd** | Sefgadin akrɔs ɛvri branch. Di eskaleshɔn rod ovas branch in Sefgadin Lida, bikɔs kɔnsɛn we rɛz insay wan branch sɔm tɛm fɔ lɛf dat branch kpatakpata. |

Chɔch-skop grant de rich ɛvri branch. Di ɔda we nɔ de tru: if yu ol branch grant insay ɛvri branch, dat stil nɔ de satisfay chɔch-skop chɛk.
