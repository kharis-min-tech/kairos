# Les rapports

<SectionClip slug="church-management/reporting" />

Kairos intègre des rapports pour suivre la santé de l'église dans le temps. Ils sont limités par le rôle : vous voyez toujours les données qui correspondent à votre niveau d'accès.

## Accéder aux rapports

Allez dans **Rapports** depuis le menu. La page s'ouvre par défaut sur l'onglet **Présences**. La direction obtient **Présences**, **Croissance** et **Évangélisation** ; tout le monde obtient **Présences** et **Évangélisation**, qui répondent à des questions sur soi plutôt que sur l'église.

Pour l'écran de présence détaillé, avec la carte de chaleur par membre et les tranches de fréquence, allez plutôt dans **Présences → Rapports**. Voir [Rapports de présence](/fr/analytics/attendance-reports).

## Les rapports de présence

Le rapport de présence montre :

- **Le taux de présence hebdomadaire** : une courbe sur les 8 dernières semaines, en pourcentage moyen
- **L'indicateur de tendance** : si la présence monte ou descend
- **Le point du mois** : une analyse de ce qui demande attention
- **Les cellules les plus suivies** : un histogramme des cellules classées par présence aux réunions

Servez-vous-en pour repérer les antennes ou les périodes où la présence fléchit, avant que cela ne devienne un vrai problème.

## Les rapports de croissance

Le rapport de croissance montre :

- **Les nouveaux membres** : les membres ajoutés sur la période, avec la comparaison d'un mois sur l'autre
- **La tendance des effectifs** : un graphique du nombre de membres dans le temps
- **Les revenants** : les membres qui se réengagent après une période d'inactivité

## Les rapports d'évangélisation

Le rapport d'évangélisation montre :

- **Les âmes atteintes** : le total recueilli sur la période
- **Le taux de conversion** : le pourcentage passé au statut Converti
- **L'évangélisation par programme** : quels programmes ont produit le plus d'âmes

## Le tableau de bord des âmes

Pour une vue analytique dédiée au suivi des âmes — entonnoir de conversion, santé des suivis, taux de passage d'une étape à l'autre — voyez la page **[Tableau de bord des âmes](/fr/platform/souls-dashboard)**.

## Exporter les données

La plupart des listes de Kairos ont un export CSV. Depuis la page Rapports :
- Utilisez les filtres pour restreindre les données
- Cliquez sur **Exporter en CSV** pour télécharger

Les listes de membres et de présences ont aussi leurs propres boutons d'export.

## La portée

| Qui | Portée du rapport |
|-----|-------------|
| Administrateur | Toutes les antennes, toutes les données |
| Habilitation d'antenne | Son antenne seulement |
| Responsable de groupe | Son département ou sa cellule seulement |
| Aucune habilitation | Une version personnelle de la page, sur sa propre activité |
