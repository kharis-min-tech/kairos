## À quoi servent les régions

Les régions permettent de grouper les antennes par géographie : par exemple, toutes les antennes du Royaume-Uni dans une région et toutes celles du Ghana dans une autre. C'est utile pour filtrer quand vous avez des antennes dans plusieurs pays.

Kairos utilise trois régions pour Kharis Church :
- **Greater Accra** : Ghana
- **Royaume-Uni** : Royaume-Uni
- **Western Area** : Sierra Leone

## Ajouter une région

Cliquez sur **+ Nouvelle région** (administrateurs uniquement) et renseignez :

| Champ | Obligatoire |
|-------|----------|
| Nom de la région | Oui |
| Pays | Oui |

Les noms de région doivent être uniques dans tout le système.

## Modifier une région

Cliquez sur la fiche d'une région pour en modifier le nom ou le pays.

## Supprimer une région

Une région ne peut être supprimée que si aucune antenne ne lui est rattachée. S'il en reste, désactivez-les ou réaffectez-les d'abord.

## Qui peut gérer les régions

Seuls les **administrateurs** peuvent créer, modifier ou supprimer des régions. Les pasteurs et les membres n'ont pas accès à la page Régions.
