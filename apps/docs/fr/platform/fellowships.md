# Cellules

<SectionClip slug="platform/fellowships" />

Les cellules sont les petits groupes au sein de chaque antenne. Kairos gère plusieurs types de cellules, une vue cartographique pour trouver un groupe proche, et le suivi complet des réunions et des présences.

## Les types de cellules

| Type | Description |
|------|-------------|
| K-Groups | Étude biblique en petit groupe |
| Kharis Express | Cellule des jeunes actifs |
| New Breeds | Cellule d'intégration des nouveaux membres |
| KOC | Kharis on Campus |
| KOC Colleges | Kharis on Campus Colleges |

Utilisez les onglets de type en haut de la page pour filtrer, ou le menu **Toutes les antennes** pour filtrer par antenne.

## Les fiches de cellule

Chaque fiche affiche :
- Le nom et le badge de type
- Le nom de l'antenne
- La description
- Les horaires de réunion (par ex. « Chaque vendredi, 18h30 »)
- Un bouton **Désactiver** (pasteurs et administrateurs uniquement)

## Trouver une cellule sur la carte

Cliquez sur **Trouver sur la carte** pour ouvrir la vue interactive. Les cellules sont placées selon leur antenne, avec un code couleur par type.

### La bulle d'information

Cliquez sur un repère pour voir le nom de la cellule, son antenne et sa prochaine réunion.

### La cellule la plus proche

Cherchez par code postal ou par pays pour trouver la plus proche. Kairos affiche :

- La distance en km
- Les temps de trajet à pied, en bus, en voiture et en train
- Des liens vers l'itinéraire via Maps ou Waze
- Les types de cellules disponibles à cet endroit

## Créer une cellule

Cliquez sur **+ Nouvelle cellule** (pasteurs et administrateurs uniquement) :

| Champ | Remarques |
|-------|-------|
| Nom de la cellule | Obligatoire, unique dans l'antenne |
| Antenne | Obligatoire |
| Type de cellule | K-Groups, Kharis Express, New Breeds, KOC, KOC Colleges |
| Responsable | Obligatoire ; doit être un membre existant |
| Co-responsable | Facultatif |
| Horaires de réunion | par ex. « Chaque vendredi, 18h30 » |
| Description | Facultative |

## Statistiques des cellules

En haut à droite de la page figurent le nombre total de cellules et combien sont actuellement actives.

| Action | Membre | Responsable | Pasteur | Admin |

| Voir la liste | Oui | Oui | Oui | Oui |
| Utiliser la carte | Oui | Oui | Oui | Oui |
