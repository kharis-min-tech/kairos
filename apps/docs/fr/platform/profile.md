## Les sections

### Informations personnelles

| Champ | Remarques |
|-------|-------|
| Prénom / Nom | Votre nom complet tel qu'enregistré |
| Deuxième prénom | Facultatif |
| E-mail | Votre e-mail de connexion |
| Téléphone | Numéro de contact |
| Sexe | Homme ou Femme |
| Date de naissance | Sert aux anniversaires |

### Adresse

Rue, ville et code postal. Utilisés pour la protection et pour vous contacter.

### Où je suis rattaché

Affiche votre **antenne de rattachement**, celle sous laquelle vous êtes inscrit.

### Ma communauté

Liste la ou les cellules dont vous êtes actuellement membre, avec le badge de type.

### Mes responsabilités

Affiche les rôles que vous détenez, par exemple « Administrateur de l'église », « Responsable de cellule, Kharis Express London » ou « Responsable du département Chorale ».

### Contact d'urgence

Nom, lien et numéro de téléphone de votre contact d'urgence. Visible seulement par vous, votre pasteur et les administrateurs.

## Modifier votre profil

Cliquez sur **Modifier le profil** en haut à droite pour mettre à jour vos informations. Les membres peuvent modifier leur propre profil à tout moment. Les pasteurs et administrateurs peuvent modifier celui de n'importe quel membre depuis la page Membres.

## Paramètres

Cliquez sur **Paramètres** en haut à droite pour accéder aux [paramètres de l'application](/fr/administration/settings).

::: tip Ce que les membres peuvent voir
Chaque utilisateur voit son propre profil en entier. Un membre ne peut pas consulter le profil d'un autre. Un pasteur voit tous les profils de son antenne. Un administrateur voit tous les profils, toutes antennes confondues.
:::
