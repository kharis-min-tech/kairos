# Formulaires et saisie

<SectionClip slug="platform/forms" />

La page Formulaires est l'endroit où se fait la saisie à l'accueil. Elle couvre les réponses à l'appel à l'autel, les demandes de baptême et de présentation, l'accueil des premières visites et les témoignages.

## Les formulaires disponibles

| Formulaire | À quoi il sert |
|------|---------|
| Première visite | Accueillir un visiteur et noter ses coordonnées pour le suivi |
| Cours Nouveaux croyants | Inscrire au parcours de discipulat quelqu'un qui a répondu à un appel à l'autel |
| Baptême | Recueillir une demande de baptême |
| Témoignage | Partager un témoignage de ce que Dieu a fait |
| Imposition du nom | Demander une cérémonie d'imposition du nom |
| Présentation d'enfant | Demander une présentation d'enfant |

Cliquez sur **Ouvrir le formulaire →** sur une fiche pour l'ouvrir.

::: warning Accès administrateurs et pasteurs uniquement
Les six formulaires ne sont accessibles qu'aux administrateurs et aux pasteurs. Les responsables qui font partie du département Admin peuvent aussi examiner les soumissions faites à l'accueil. Les membres ordinaires n'ont pas accès à la page Formulaires.
:::

## Les soumissions

### Filtrer les soumissions

| Filtre | Options |
|--------|---------|
| Type de formulaire | Tous, Première visite, Cours Nouveaux croyants, Baptême, Témoignage, Imposition du nom, Présentation d'enfant |
| Statut | Tous, En attente, Examiné, Traité |
| Du / Au | Période |

### Exporter les soumissions

Cliquez sur **Exporter en CSV** pour télécharger toutes les soumissions filtrées sous forme de tableur. Utile pour les suivis menés hors du système.

## Visiteurs dormants

Cliquez sur **Visiteurs dormants** pour archiver en masse les fiches de contact créées par formulaire et restées sans suite : des personnes venues par un formulaire de visite ou d'appel à l'autel, sans engagement depuis. Cela garde l'annuaire propre sans jamais supprimer définitivement une fiche.

## Comment les soumissions rejoignent les autres modules

- Une soumission **Cours Nouveaux croyants** → crée automatiquement une inscription dans le parcours [Nouveaux croyants](/fr/platform/new-believers)
- Une soumission **Première visite** → crée une fiche de contact pour le suivi
- Une soumission **Baptême** → crée une demande qui apparaît dans la file d'examen des administrateurs
- **Imposition du nom / Présentation** → crée une demande à planifier par les administrateurs
