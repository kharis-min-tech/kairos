# Programmes d'évangélisation

<SectionClip slug="platform/outreach" />

La page Programmes d'évangélisation est l'endroit où les actions d'évangélisation se créent et se gèrent. Les programmes sont rattachés à une antenne : un membre ne peut s'inscrire qu'aux programmes de sa propre antenne.

## La liste des programmes

Les programmes s'affichent dans un tableau :

| Colonne | Description |
|--------|-------------|
| Nom du programme | Le nom de l'action d'évangélisation |
| Date | Quand le programme a lieu |
| Lieu | Où il se déroule |
| Coordinateur | Le membre responsable |
| Âmes atteintes | Combien d'âmes ont été recueillies lors de cette action |
| Inscrits | Le nombre d'ouvriers inscrits |
| Statut | En cours ou Terminé |
| Inscriptions | Ouvertes ou Fermées |
| Actions | Modifier ou voir le détail du programme |

Utilisez les onglets **Programmes en cours** et **Programmes passés** pour basculer entre l'actuel et l'historique. Cherchez par nom dans la barre de recherche.

## Créer un programme

Cliquez sur **+ Créer un programme** (responsables, pasteurs et administrateurs) :

| Champ | Remarques |
|-------|-------|
| Nom du programme | Obligatoire |
| Antenne | Obligatoire ; détermine qui peut s'inscrire |
| Date | Obligatoire |
| Lieu | Obligatoire |
| Adresse / Ville | Facultatif |
| Description | Facultative |
| Coordinateur | À relier à un membre ; la personne responsable |

## S'inscrire comme ouvrier

Un membre peut s'inscrire lui-même comme ouvrier sur tout programme en cours de son antenne. Une fois inscrit, il apparaît dans la liste des ouvriers du programme et voit ses prochaines affectations depuis sa fiche.

## Recueillir les âmes

Après un programme, les coordinateurs et les responsables consignent les âmes atteintes en reliant les fiches de recueil au programme. Chaque âme recueillie lors de l'action apparaît dans le [Suivi des âmes](/fr/platform/souls-pipeline) et alimente le compte **Âmes atteintes**.

## Qui peut gérer l'évangélisation

| Action | Membre | Responsable | Pasteur | Admin |
|--------|--------|--------|--------|-------|
| Voir les programmes | Oui (son antenne) | Oui | Oui | Oui |
| S'inscrire comme ouvrier | Oui (son antenne) | Oui | Oui | Oui |
| Créer des programmes | Non | Oui (ceux qu'il coordonne) | Oui | Oui |
| Modifier des programmes | Non | Oui (les siens) | Oui | Oui |
| Voir toutes les inscriptions d'ouvriers | Non | Oui (ses programmes) | Oui | Oui |
