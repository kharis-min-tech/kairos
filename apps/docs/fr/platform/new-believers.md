# Nouveaux croyants

<SectionClip slug="platform/new-believers" />

La page Nouveaux croyants suit le parcours de discipulat des membres récemment convertis, depuis leur premier appel à l'autel ou leur conversion lors d'une action d'évangélisation, à travers quatre séances d'enseignement, jusqu'à ce qu'ils rejoignent un département comme membres à part entière.

## Le parcours d'un coup d'œil

Trois chiffres apparaissent en haut :

| Indicateur | Ce qu'il veut dire |
|------|---------|
| Actifs | Les membres actuellement dans le parcours |
| Sans avancée depuis 7 jours et plus | Les inscriptions qui stagnent ; à reprendre en main |
| Ont rejoint un département | Ont terminé tout le parcours |

## Le tableau Kanban

Le parcours s'affiche en tableau Kanban, une colonne par étape :

| Étape | Description |
|-------|-------------|
| Séance 1 | Les fondements de la foi |
| Séance 2 | Qui est chrétien |
| Séance 3 | Travailler à son salut |
| Séance 4 | L'importance de la communion fraternelle |
| Terminé | Toutes les séances faites |
| A rejoint un département | Pleinement intégré à la vie de l'église |

Chaque fiche affiche :
- Le nom du membre et la date d'inscription
- L'enseignant attribué (avec ses initiales)
- Le mentor attribué (avec ses initiales)

## Inscrire un nouveau croyant

Cliquez sur **+ Inscrire un membre** pour lancer quelqu'un dans le parcours. Quand une âme est marquée convertie dans le [Suivi des âmes](/fr/platform/souls-pipeline), une inscription est créée automatiquement.

## Trier et chercher

- Cherchez par nom de membre ou d'enseignant dans la barre de recherche
- Triez par **Date d'ajout**, **Nom** ou **Dernière activité**
- Filtrez par étape avec les onglets

## Les séances

Cliquez sur **Séances** pour gérer le calendrier : dates, sujets, lieux, et quel enseignant mène chaque séance.
