# Asɛmpatrɛw Nhyehyɛeɛ

<SectionClip slug="platform/outreach" />

Asɛmpatrɛw Nhyehyɛeɛ kratafa no so na wɔyɛ asɛmpatrɛw dwumadie na wɔhwɛ so. Nhyehyɛeɛ no bata asɔre baa ho, enti asɔremufoɔ tumi kyerɛw wɔn din wɔ wɔn ankasa asɔre baa nhyehyɛeɛ mu nko ara.

## Nhyehyɛeɛ nhwɛmu

Wɔkyerɛ nhyehyɛeɛ no wɔ tebo mu:

| Fa | Nkyerɛkyerɛmu |
|--------|-------------|
| Nhyehyɛeɛ Din | Asɛmpatrɛw dwumadie no din |
| Ɛda | Bere a nhyehyɛeɛ no kɔ so |
| Beaeɛ | Baabi a ɛkɔ so |
| Ɔhwɛsofoɔ | Ɔmanfoɔ a adwuma no da ne so |
| Akra a Wɔduruu Wɔn Nkyɛn | Akra dodoɔ a wɔnyaa wɔn wɔ dwumadie yi ase |
| Wɔn a Wɔakyerɛw Din | Adwumayɛfoɔ dodoɔ a wɔakyerɛw wɔn din |
| Tebea | Ɛrekɔ so anaa Awie |
| Dinkyerɛw | Abue anaa Ato mu |
| Dwumadie | Sesa anaa hwɛ nhyehyɛeɛ no mu nsɛm |

Fa **Nhyehyɛeɛ a Ɛrekɔ so** ne **Nhyehyɛeɛ a Atwam** tab no di dwuma na sesa deɛ wohwɛ. Hwehwɛ nhyehyɛeɛ din wɔ ɔhwehwɛ beaeɛ no.

## Yɛ nhyehyɛeɛ foforɔ

Mia **+ Yɛ Nhyehyɛeɛ** (Akannifoɔ, Asɔfoɔ, ne Sohwɛfoɔ):

| Beaeɛ | Nsɛm |
|-------|-------|
| Nhyehyɛeɛ din | Ɛho hia |
| Asɔre baa | Ɛho hia; ɛkyerɛ hwan na ɔtumi kyerɛw ne din |
| Ɛda | Ɛho hia |
| Beaeɛ | Ɛho hia |
| Akyerɛwdeɛ / Kuropɔn | Ɛho nhia |
| Nkyerɛkyerɛmu | Ɛho nhia |
| Ɔhwɛsofoɔ | Fa bata ɔmanfoɔ bi ho; onipa a adwuma no da ne so |

## Kyerɛw wo din sɛ adwumayɛfoɔ

Asɔremufoɔ tumi kyerɛw wɔn din sɛ adwumayɛfoɔ wɔ nhyehyɛeɛ biara a ɛrekɔ so wɔ wɔn asɔre baa mu. Sɛ wɔkyerɛw wie a, wɔpue wɔ nhyehyɛeɛ no adwumayɛfoɔ nhwɛmu mu na wɔhunu wɔn asɛmpatrɛw adwuma a ɛreba firi wɔn nkrataa so.

## Akra a wɔnya

Nhyehyɛeɛ bi akyi no, ahwɛsofoɔ ne akannifoɔ kyerɛw akra a wɔduruu wɔn nkyɛn denam akra nkrataa a wɔde bɛbata nhyehyɛeɛ no ho so. Ɔkra biara a wɔnyaa no wɔ dwumadie no ase no pue wɔ [Akra Ɔkwan](/tw/platform/souls-pipeline) mu na ɔka **Akra a Wɔduruu Wɔn Nkyɛn** dodoɔ no ho.

## Hwan na ɔtumi hwɛ asɛmpatrɛw so

| Dwumadie | Ɔmanfoɔ | Kannifoɔ | Ɔsɔfoɔ | Sohwɛfoɔ |
|--------|--------|--------|--------|-------|
| Hwɛ nhyehyɛeɛ | Aane (ɔno ara asɔre baa) | Aane | Aane | Aane |
| Kyerɛw din sɛ adwumayɛfoɔ | Aane (ɔno ara asɔre baa) | Aane | Aane | Aane |
| Yɛ nhyehyɛeɛ | Daabi | Aane (deɛ ɔhwɛ so) | Aane | Aane |
| Sesa nhyehyɛeɛ | Daabi | Aane (ɔno ara dea) | Aane | Aane |
| Hwɛ adwumayɛfoɔ dinkyerɛw nyinaa | Daabi | Aane (ɔno ara dea) | Aane | Aane |
